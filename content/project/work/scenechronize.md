"scenechronize" started out as an application for planning movie productions. Doing script breakdown and managing departmental planning. It pivoted to more of a document management and distribution system, but the original functionality continued to be used. It's used by most movie and TV productions in the US.

It was written in Java, using GWT to translate to Javascript. GWT is a road less travelled, but I think Java helped us manage the codebase (this was pre-typescript). Coding the UI was reminiscent of writing desktop applications, and we were able to share code between client and server.

I did a lot of the design for scenechronize with a small team of strong engineers. I also wrote the companion iOS application in ObjectiveC.

Around 2020, I moved on to the Movie Magic Budgeting rewrite, but continued to help out with architecture and debugging issues that the team got stuck on.
