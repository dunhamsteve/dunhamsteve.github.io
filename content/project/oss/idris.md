Idris2 is a dependent typed programming language that is used in computer science research. It is based on Quantitative Type Theory (QTT). Idris2 is designed to be used as a practical programming language, in addition to acting as a proof assistant.

I've enjoyed contributing to Idris over the last few years. I've learned a lot and the community is very welcoming.
